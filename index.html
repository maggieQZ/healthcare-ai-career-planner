Healthcare AI 作品集：两个相互补充的核心项目

Project 1 · Weeks 1–14 · 主项目

OncoSurv: SEER Multi-Cancer Survival Modeling Platform

Objective：为 ovarian、pancreatic 和 colorectal cancer 建立共享的可复现数据/训练框架与 cancer-specific 生存模型，通过统一 API 返回 1/3/5 年 population-based modeled survival；比较 pooled model 与癌种专属模型的校准和泛化表现。仅为研究作品，不用于个体临床决策。

  • Shared SQL cohort pipeline + cancer-specific feature schemas
  • Cox / survival ML、temporal validation、C-index、Brier score 与 calibration
  • Model registry、统一 API、自动测试、Docker、CI/CD 与 model cards
PythonSQLSurvival AnalysisReusable ML PipelineModel RegistryAPIDocker
Project 2 · Weeks 15–18 · EHR + AI项目

Synthetic Oncology EHR Timeline & Evidence Assistant

Objective：使用 Synthea 合成 EHR（无真实患者隐私风险），把 conditions、encounters、medications、observations 和 procedures 转换为 FHIR-aware 患者时间线，并结合 NCI 公开资料生成带引用的非诊断型摘要与问答。

  • 读取 FHIR R4/CSV，建立 patient-level longitudinal data model
  • 构建 EHR timeline、数据质量检查、术语映射与 API
  • RAG、引用、拒答、测试、Docker、logging 与 evaluation report

Week 2 · Portfolio v0.1

平台设计 + Ovarian MVP

公开 GitHub repo、共享 pipeline 架构、三个癌种的 cohort/schema 计划，并先完成 ovarian cohort definition。此时即可放入 Resume A 的 Projects 区并标记 In Progress。

Week 4 · Portfolio v0.2

Reusable SQL Cohorts + Data QA

共享纳排逻辑支持 ovarian、pancreatic、colorectal，并输出各癌种 cohort flow、missingness report 和验证规则。

Week 5 · Portfolio v0.3

Multi-Cancer EDA

发布三个癌种的 Table 1、Kaplan–Meier 曲线和数据差异说明；该版本本身已是可展示的完整分析交付物。

Week 8 · Portfolio v0.5

Pooled vs Cancer-Specific Benchmark

比较 pooled baseline 与癌种专属 baseline，完成 temporal validation、calibration 和 model-card draft。

Week 10 · Portfolio v0.7

Multi-Cancer Survival ML

发布三个 cancer-specific Cox/Random Survival Forest 模型及 C-index、Brier score、1/3/5 年校准对比。

Week 12–14 · Portfolio v1.0

Model Registry + API + Demo

根据 cancer type 自动加载对应 schema/model，加入统一 API、pytest、Docker、CI/CD、部署链接和三分钟演示。

每周投递策略

Weeks 1–2 · 5–8份/周

用既有经验先启动

Healthcare Data Analyst、Cancer/Oncology Data Analyst、Clinical Data Analyst、Research Data Analyst、SAS Programmer。使用 Resume A；Week 2 加入项目 v0.1。

Weeks 3–7 · 10份/周

用 SQL/EDA 版本扩大范围

继续上述岗位，并加入初级 Healthcare Data Scientist、Research Data Scientist、Predictive Analytics Analyst。使用 Resume A/B；Week 4、5 更新项目链接和 bullet。

Weeks 8–20 · 12–15份/周

模型成熟后再扩大到 AI

Healthcare Data Scientist、Applied AI Engineer、Healthcare ML Engineer、AI Application Developer、RAG Developer。Week 8 先试投 DS；Week 12 后才把 AI Engineer 作为重要投递线。

有效投递 = 地点为 Columbus, OH 或明确允许 Ohio 的 US Remote；没有公民/绿卡硬门槛；核心要求匹配约 60% 以上；保存 exact posting URL。不要把 “Remote US” 自动等同于允许所有州或提供 sponsorship。
